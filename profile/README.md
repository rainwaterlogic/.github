# Rainwater

Rainwater builds local-first trading research and workflow tools for traders who want visible systems, reproducible research, and operator-grade tooling.

## Current Work

- [rainwater-tradingview-mcp](https://github.com/rainwaterlogic/rainwater-tradingview-mcp) - Rainwater-maintained TradingView MCP bridge for local chart context, Pine workflows, and member scripts.

More public repositories will come after the TradingView MCP lane is hardened.

## For Developers

We care about tools that are:

- local-first where possible
- explicit about data sources and limitations
- compact enough for AI agents to use without wasting context
- safe around credentials, broker access, and account state
- useful to real operators, not only demos

## Boundaries

Rainwater open-source tools do not redistribute market data, bypass paywalls, or replace a user's own accounts and subscriptions. Bring your own TradingView, brokerage, and data access where required.
